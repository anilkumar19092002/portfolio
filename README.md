# FDE Engineers Portfolio

An upgraded Next.js portfolio for the Forward Deployed Engineering team.

## What changed in this revision
- Stronger premium hero section with layered cards and improved content hierarchy.
- Added a more visible **Digital Marketing** section so marketing is clearly included.
- Added more effective copy to explain the team, services and value proposition.
- Added multiple **realistic AI-generated images** for project storytelling.
- Added a refined **custom scrollbar** and scroll-based interface polish.
- Added a floating **scroll-to-top** button and stronger section transitions.
- Improved the services, capabilities and project sections to feel more standard and client-ready.
- Reworked the portfolio so it feels more dynamic, attractive and complete.

## Run locally
```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build
```bash
npm run build
npm start
```

## Notes
- Showcase visuals are bundled locally inside `public/projects/`.
- Team images are bundled locally inside `public/team/`.
- The portfolio uses Next.js 14, React 18, Tailwind CSS and Framer Motion.
